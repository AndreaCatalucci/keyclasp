# Keyclasp 0.2.0-beta.2

This beta includes the security remediation from PRs #15–18.

- Fresh passphrase vaults use interactive custody by default; unattended machine custody requires explicit selection.
- Custody changes clean up obsolete SQLite representations and retire machine keys when no machine records remain.
- Backup and restore handle the complete SQLite file set and resume interrupted recovery.
- Streaming output protection detects overlapping secrets and stops supervised child processes on a leak.
- macOS helper validation and environment handling are hardened. Linux shutdown and unsupported Node-version rejection are corrected.

Supported targets are macOS arm64 and glibc Linux arm64/x64 with Node.js 24 or 26. Install this prerelease with `npm install -g keyclasp@beta` after registry publication.

This is a beta release, not a production-security certification. Full replacement-artifact qualification, physical authorization checks, and independent external assurance remain incomplete. The macOS helper is ad hoc signed; Developer ID signing and notarization are not included. The failed KC-Q01 receipt remains historical evidence.

Existing vaults retain their legacy default until an authorized default change. Back up before upgrading. Live cleanup does not revoke old backups, snapshots, or previously exposed credentials; provider-side rotation is required when those copies must lose access.

Publication does not install this version into the operator environment or migrate an existing vault.
