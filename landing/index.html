How It Works

Three commands. Your secrets stay secret.
1

Store Your Secrets

Encrypt API keys, tokens, and passwords into a local AES-256-GCM vault.


echo "sk-abc123" | keyblind set KEY
2

Sandbox Your .env

Replace real values with deterministic fakes. AI agents see only the fakes.


keyblind sandbox
3

Run With Confidence

Your code runs with real secrets injected as env vars. Your AI never sees them.


keyblind run -- npm start
