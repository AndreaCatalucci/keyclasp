### Description (Detailed)
```
Keyblind scans web pages for exposed API keys, tokens, and secrets, and prevents you from accidentally pasting them into AI chat sites.

WHAT IT DOES:
- Scans web pages for 13+ types of secrets (OpenAI keys, GitHub tokens, AWS keys, Stripe keys, JWTs, private keys, and more)
- Shows a red warning banner when secrets are found on a page
- Intercepts paste events on AI chat sites and replaces real keys with placeholder markers
- Popup shows vault status and detected secrets on the current page

REQUIRES:
- Keyblind CLI (free, open source) running on your machine for vault integration
- Install: npm install -g keyblind

PRIVACY:
- 100% local — no data ever sent to any server
- No analytics, no telemetry, no tracking
- Open source (MIT): https://github.com/aarifmms/keyblind

Keyblind is part of the Keyblind secrets management platform — the MCP-native encrypted vault for AI agents. Learn more at https://keyblind.dev
```
