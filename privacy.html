Privacy Policy — Keyblind

Last updated: July 18, 2026

Data Collection

Keyblind does not collect analytics, telemetry, advertising identifiers, or usage data. The project does not operate an account system or hosted vault service.

How It Works

The default vault encrypts secrets on your machine. Sandboxing replaces project values with deterministic fakes, and guarded execution injects selected secrets into a child process at runtime. Programs you run can make their own network requests; Keyblind does not control their behavior.

Local Storage

Vault data, encryption material, configuration, history, aliases, and audit metadata are stored locally under the user's Keyblind directory. Project configuration may also be stored in a local .keyblind file.

Optional Backends

If you configure 1Password, Bitwarden, AWS, GCP, Azure, or another external backend, its command-line tool and service handle data under that provider's terms. The local backend requires no network connection.

Third Parties

Keyblind does not sell user data or include advertising. Data reaches a third party only when you configure an external backend, share an encrypted link through another service, or run a program that transmits it.

Contact

Keyblind is open source under the MIT license. For questions, use github.com/AndreaCatalucci/keyblind/issues.
