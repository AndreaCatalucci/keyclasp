Privacy Policy — Keyclasp

Last updated: August 4, 2026

Data Collection

Keyclasp does not collect analytics, telemetry, advertising identifiers, or usage data. The project does not operate an account system or hosted vault service.

How It Works

The vault encrypts secrets on your machine with AES-256-GCM. Guarded execution (keyclasp run) injects selected secrets into a child process at runtime and never routes them through Keyclasp's own output. Programs you run can make their own network requests; Keyclasp does not control their behavior.

Local Storage

Vault data and encryption key material are stored locally under the user's Keyclasp directory (~/.keyclasp/ by default), with owner-only file permissions. Nothing is stored outside that directory.

Third Parties

Keyclasp does not sell user data, include advertising, or make network requests of its own. Data reaches a third party only if a program you run through keyclasp run transmits it.

Contact

Keyclasp is open source under the MIT license. For questions, use github.com/AndreaCatalucci/keyclasp/issues.
