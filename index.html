A Local Encrypted Vault for Coding Agents

Store credentials locally, encrypted. Inject them into trusted commands only when needed, never into the agent's own context, and catch accidental output leaks.

npm install -g keyclasp && keyclasp init
Node.js 24+. Local vault. Guarded execution. Zero telemetry.

How It Works

Store locally, encrypted. Run with secrets injected. Your secrets stay secret.
1

Store Your Secrets

Encrypt API keys, tokens, and passwords into a local AES-256-GCM vault.


keyclasp set SECRET_API_KEY -
2

Agent Sees Names Only

An agent can list what's available without ever seeing a value.


keyclasp list
3

Run With Secrets

Inject secrets into a trusted child process and stop detected output leaks.


keyclasp run --env SECRET_API_KEY -- npm start
Works with local coding agents

A Deliberately Small Surface

AES-256-GCM Vault

Guarded Run
